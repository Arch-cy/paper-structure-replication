# 六模块操作指南

只读取当前任务涉及的模块。下面的“完成条件”用于判断能否继续工作；未满足时交付已完成部分和明确缺口，不伪造补齐。

## 1. 选择参照

**输入：** 研究卡、候选论文或可用的文献检索入口。

把课题拆成三类词，例如“高校校园文化”是主题，“实践特征”是问题形态，“扎根理论”是方法。优先查“问题形态 + 方法”，再结合主题与目标文体；这有助于找到对象不同但结构可迁移的论文。跨主题借鉴需另查领域证据，不能把另一对象的结果迁过来。

没有数据库访问或检索工具时，处理用户提供的材料，或给出检索式和筛选表。不能编造已检索到的候选或暗示访问了未访问的数据库。

对每个真实候选判断：

| 维度 | 核查内容 | 处理方式 |
|---|---|---|
| 任务适配 | 研究问题形态、文体、篇幅与读者是否相近 | 差异说明可迁移范围 |
| 方法适配 | 方法目的、对象、数据结构及假设是否匹配 | 不匹配时不作为方法模板 |
| 规范与完整性 | 样本、过程、分析、证据与局限是否充分交代 | 高层级期刊也允许判为有缺陷 |
| 实际可用性 | 用户是否能获得相应数据、资源与操作能力 | 把必要改造写入计划 |
| 时效与载体 | 是否符合当前领域及目标要求 | “近五年”是起始偏好，不是淘汰经典方法的规则 |

检索无结果时，每次放宽一个可放宽条件，例如目标刊物、时间窗或主题近义词；记录变化。不能在不说明的情况下把相关性较弱的论文当成高度适配。默认保留一篇主范文，明确各辅助来源的用途；用户已有合理多来源框架时不强行推倒重来。

**输出：** 主范文及选择理由、可用范围、缺陷、辅助来源用途、核验状态。

**完成条件：** 能定位实际材料并解释为什么借鉴；没有可核验范文时，输出暂定框架并注明不是对真实范文的拆解。

## 2. 迁移框架

**输入：** 范文全文或可核验目录、用户研究问题。

先做“去主题化”：例如把“某政策的结构特征”归纳为“呈现分析结果及类别关系”，再做“重新适配”：确定新研究需要哪些类别、证据与分析。参照目录可用于初步结构分析，但不能据此推断正文中的实际方法或发现。

使用四列完成映射：原节功能 → 用户研究中的作用 → 所需证据/分析 → 保留、拆分、合并、删除或新增的理由。引言可按问题背景、已有研究、缺口、研究问题与研究方案组织，但依目标学科规范调整；不强制把全部功能分别设成标题。

画出最小链条：研究问题 → 数据/文本 → 分析操作 → 结果产物 → 可支持的结论。出现孤立章节时检查其功能；出现没有证据的结论时收窄主张或补研究计划。

**输出：** 有功能与证据要求的提纲、需要解决的结构差异。

**完成条件：** 每个核心问题都有分析去向，每个核心结论有证据路径。篇幅比例按目标要求和证据复杂度分配，不复制范文章节数量。

## 3. 落实数据收集与分析

**输入：** 当前问题、已选或候选方法、可获得的数据与实际操作记录。

至少交代分析单位、总体或材料范围、纳入/排除标准、抽样理由、来源与时间、预处理、分析操作、质量控制及保留的记录。写计划时区分“预期可获得”与“已经获得”；写方法章时只报告确实做过的操作。

| 研究类型 | 需明确的实际操作 | 可核验记录与限制 |
|---|---|---|
| 思辨/文献研究 | 文本范围、选择依据、概念界定、论证与反例处理 | 版本/位置、摘录与解释区分、反证材料；不预设必须系统综述 |
| 质性研究 | 方法流派、抽样与补样、访谈/文本收集、编码或主题形成、反例与研究者反思 | 原始片段→分析标记→类别/主题→解释的链条；报告适用的充分性依据 |
| 量化研究 | 估计目标、变量操作化、抽样、缺失值处理、模型假设、不确定性、稳健性 | 数据字典、清洗与分析代码、实际输出；没有识别依据不能把相关写成因果 |
| 混合研究 | 各部分分别回答什么问题、执行次序、如何整合证据 | 合流/冲突的处理记录；不是把两种方法并列就称为混合研究 |

扎根理论只是原书的贯穿例子，不是默认研究方法。其不同流派对先验理论、编码程序和质量标准存在差异，应采用有依据且内部一致的方案。开放—主轴—选择性编码不适用于所有质性研究；词频与聚类也不能自动代替意义解释。

若涉及一致性或饱和度等检查，交代方法定义、数据来源、操作过程、判定依据与结果。没有相应设计或记录时，不编造“已饱和”“信度大于某值”。原书出现的 0.93、0.913 或 0.8 是具体示例，不是本技能的通用标准。

可复现要求是使别人能检查和尽可能重做研究过程；不能承诺重新访谈会得到完全相同的回答。涉及受访者或个人信息时，将适用的同意、匿名化和研究伦理要求写入实际方案；网络抓取需在可访问且有权使用的数据范围内进行。

**输出：** 可执行研究操作清单；已有研究则输出过程与记录对照、分析产物、尚缺环节。

**完成条件：** 方案与当前条件相容。生成结果章节还需实际材料及可核对分析，方法名称与软件名称本身不算结果证据。

## 4. 匹配理论基础

**输入：** 研究问题、核心概念、可核验理论或相关研究。

可选现成理论、既有研究的解释焦点，或二者结合。单概念研究优先厘清含义、边界与相关争议；多概念研究还要说明选择这些概念及其关系的依据，但不把“单概念=质性”“多概念=量化”当规则。

按“理论/观点 → 相关命题 → 适用条件 → 当前现象 → 支持证据 → 冲突/限制”检查。理论模型需要调整时，逐项说明改动、理由和待检验后果，不能把改完的模型称为已经验证。探索性研究须说明理论在研究中的位置，避免提前把材料塞进预设类别。

检索可尝试主题近义词与“理论基础/理论视角/理论支撑”等位置词。有无合适理论取决于材料，不能从近义词相似推断理论必然适用。查不到时如实报告，转向可核验的概念和文献讨论。

**输出：** 概念定义及出处、理论或研究焦点的适配说明、需要验证的关系及边界。

**完成条件：** 理论实际承担解释工作，关键关系有依据或明确的待检验身份，没有仅为装饰而增加的理论标题。

## 5. 提炼结构要素和论证逻辑

**输入：** 目标章节、范文相应片段与用户证据。

从宏观到中观，再按需到微观：

- 章节层：本节完成什么任务，与前后章节怎样衔接。
- 段落层：中心主张、支持材料、分析解释、反例/限制、与下一段的关系。不是每段都需要把这些功能各写一句。
- 句子层：例如界定、比较、限定、因果推断、解释或研究行动。提炼关系而非复刻词序和标点。

对推理关系逐项判断：证据真的支持主张吗？转折是否只是措辞？把文献空白当作研究价值是否足够？观察能否支撑因果措辞？没有连词的句子也需检查是否存在跳步。

“视角—材料—方法—目标—意义”可作为研究计划功能槽位。填入当前研究的真实内容后，用自己的句子表达；缺少的槽位允许删除，尚未实现的目标用计划性措辞。

**输出：** 可迁移功能图、适配后的段落计划或原创片段、具体修改理由。

**完成条件：** 论证链成立、文字依赖当前证据。主张学术贡献时需比较已有研究，在问题、材料、识别/分析、发现或解释上说明增量，单纯改写风格不算。

## 6. 布局文献与证据

**输入：** 提纲、方法方案、当前来源。

为来源建立编号和状态：`已核验相关内容`、`仅元数据/摘要`、`二手线索`、`待核验`。核验到片段不代表读过全文；书中引用的原论文按二手线索处理，直至检查原文。

| 用途 | 解决的问题 | 何时阅读与核验 |
|---|---|---|
| 结构参照 | 如何安排内容与论证 | 拆解相关章节时 |
| 方法依据 | 操作为何适用，如何实施与解释 | 设计或实施相应操作前 |
| 领域证据 | 概念、事实、已有观点与争议 | 将主张写入实质正文前 |

一篇文献可以承担多种用途，逐项记录即可。收集和深度阅读分层推进：不要求一开始读完所有文献，但用于具体主张的相关内容必须核验。维护“主张ID → 来源ID及定位 → 支持内容 → 可支持范围 → 核验状态”，引用有冲突时保留争议，不能挑有利结果拼成确定结论。

引用格式按目标要求，来源条目只写可核验字段。不造 DOI、页码、年份或作者；没有页码的网页可用章节、标题或可定位段落。下载到的文件应能关联文献编号及用途。

**输出：** 分类来源表、主张—证据矩阵、针对缺口的补充检索清单。

**完成条件：** 当前产物所需的关键主张都有可用证据或显式缺口；不以“已下载二十篇”替代覆盖度判断。
