# 论文结构迁移与原创初稿

从参考论文中提炼框架、论证逻辑与研究操作，形成适配新课题的研究方案、文献布局或有证据支撑的原创初稿。

技能名称：`paper-structure-replication`。

## 适用任务

- 拆解参考论文，将章节标题还原为研究功能，再形成自己的提纲。
- 按课题准备数据收集、分析、理论与文献方案。
- 根据已有真实材料撰写全文或指定章节。
- 参照范文定位并修改已有稿件中的局部问题。

## 工作流程

选择参照 → 迁移框架 → 落实研究操作 → 匹配理论 → 提炼论证要素 → 布局文献。

按当前任务选择入口，不必每次从头执行。用主范文维持结构一致，用辅助范文解决具体缺陷；每一节都说明研究问题、所需证据和预期产物。

## 使用方法

入口为 [SKILL.md](SKILL.md)，配套参考文件在 [references/](references/)。可以下载 [完整技能包](dist/paper-structure-replication.zip)，将其中的技能文件夹提供给支持该格式的工具。普通对话中使用时，同时提供入口及当前任务需要的参考文件。

示例请求：

> 请使用这份技能。我的课题是……，要交付的是研究方案/章节框架/初稿/修改稿，已有参考论文与材料如下……。请按当前进度执行相关模块，缺证据处明确标记。

技能加载后可通过 `$paper-structure-replication` 调用。只输入名称不会自动加载尚未提供的技能。

结构迁移不能替代真实研究。技能区分拟执行与已执行，不补造样本、数据、检验结果或引文；句式变化和多篇拼接不能证明学术贡献。缺少材料时交付可完成部分及明确缺口。

已完成格式、内部链接和打包检查，并做过八个场景的手工规则走查；尚未进行真实课题效果对照实验。
